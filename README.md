# livresgourmands.net

## Description du projet

livresgourmands.net est une plateforme de commerce électronique spécialisée dans la vente de livres de cuisine.

Le site permet aux utilisateurs de rechercher et consulter des ouvrages, gérer un panier, effectuer des commandes, créer des listes de cadeaux et partager des avis et commentaires.

La plateforme propose également une gestion du catalogue, du stock, des catégories et des utilisateurs administratifs.

## Objectifs de l'étape 01 : Les fondations du site

Cette première étape consiste à analyser et modéliser le système avant le développement.

Les objectifs sont :

- Comprendre le cahier des charges du projet.
- Identifier les acteurs du système et leurs fonctionnalités.
- Réaliser un diagramme de cas d’utilisation UML.

## Acteurs du système

### Front Office

- Internaute :
  - Rechercher des ouvrages.
  - Consulter des ouvrages.

- Client :
  - S’enregistrer.
  - Se connecter.
  - Gérer un panier.
  - Passer des commandes.
  - Créer des listes de cadeaux.
  - Donner des avis et commentaires.

- Ami :
  - Consulter une liste de cadeaux.
  - Acheter depuis une liste de cadeaux.

### Back Office

- Éditeur :
  - Gérer les descriptions des ouvrages.
  - Gérer les catégories.
  - Valider les commentaires.

- Gestionnaire :
  - Gérer le catalogue.
  - Gérer le stock.
  - Suivre les ventes.

- Administrateur :
  - Maintenir le site.
  - Gérer les utilisateurs.
  - Superviser les transactions.

### Système externe

- Prestataire de paiement sécurisé :
- Effectuer les paiements en ligne sécurisés.
